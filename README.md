# yuci

## token-meter：Token 用量监测插件

一个给 Claude Code 用的小插件，帮你随时看到 token 花了多少。

### 它会做什么

- **每轮回答结束后**，在回答下面加一行小字，例如：

  ```
  Token 本轮 8.2万（输入 2,032 · 输出 1,296 · 缓存读取 7.9万） ｜ 上下文 41% · 5小时额度 23% · 每周额度 8%
  ```

- **输入 `/tokens`**，查看完整报告：本轮用量、本次对话累计用量、上下文占用、
  5 小时额度和每周额度用了多少、大约多久后重置。

### 命令

| 输入 | 作用 |
| --- | --- |
| `/tokens` | 查看完整的用量报告 |
| `/tokens off` | 关闭每轮回答后的那一行提示 |
| `/tokens on` | 重新打开提示 |
| `/tokens panel` | 打开一个常驻的用量面板（界面支持时） |

### 这些数字是什么意思

- **输入**：你发给 Claude 的内容（包括它读的文件、工具结果）。
- **输出**：Claude 写出来的内容。
- **缓存读取**：之前已经处理过、这次直接复用的内容。数字通常很大，但消耗的额度只有正常输入的一小部分。
- **上下文**：这次对话的“记忆空间”用了多少，接近 100% 时旧内容会被自动压缩。
- **5小时额度 / 每周额度**：订阅套餐的用量上限已经用掉的百分比。

### 怎么用

**在这个仓库里开对话（网页、手机 App、桌面端都可以）**：插件放在
`.claude/skills/token-meter/` 里，会随仓库自动加载，不需要安装。

**想在自己电脑的其他项目里也用**：在 Claude Code 终端里输入

```
/plugin install token-meter --marketplace yucicc/yuci
```

桌面 App 里：点输入框旁边的 +，选 Plugins，Add marketplace 填 `yucicc/yuci`，再 Add plugin。

### 说明

- 统计的是**当前这次对话**的用量，换一个新对话会从零开始计。
- 子任务（Claude 派出去的小助手）的用量也会算进去。
- 额度百分比来自 Claude 自己上报的数据；如果你用的不是订阅套餐，这一项不会显示。
